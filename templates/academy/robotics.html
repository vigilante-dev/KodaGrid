🔧 Visual Assembly Guide

1

Sort and inventory your parts

Lay everything out. Match each part to the inventory list inside the box lid. Count all cables — you need exactly 6.

2

Connect the Large Motors to ports A and D

Each motor gets one cable. Port A = left motor, Port D = right motor. Push the connectors firmly until you hear a click.

💡 Tip: Motor cables are 25cm (short). Sensor cables are 35cm (long). Don't mix them up!
3

Connect the Color Sensor to port 3

The color sensor detects red, green, blue, yellow, white, and black. Connect it to port 3 on the right side of the brick.

4

Insert batteries and power on

Insert 6 × AA batteries OR connect the rechargeable pack. Press the center button to power on. The screen should show the LEGO logo then the main menu.

🔋 Rechargeable tip: The official Li-ion pack lasts 3× longer than AA batteries and is better for the environment.
5

Download LEGO Mindstorms Education EV3 app

Free on Windows, Mac, iPad, and Chromebook. Connect your EV3 via USB (or Bluetooth: Settings → Bluetooth → Search for devices).

Your first EV3 Python program
#!/usr/bin/env pybricks-micropython
from pybricks.ev3devices import Motor, ColorSensor
from pybricks.parameters import Port, Color
from pybricks.tools import wait

# Connect motors and sensor
left_motor  = Motor(Port.A)
right_motor = Motor(Port.D)
color_sensor = ColorSensor(Port.S3)

print("Robot ready. Starting drive sequence...")

# Drive forward for 2 seconds
left_motor.run(500)
right_motor.run(500)
wait(2000)

# Stop and check colour
left_motor.stop()
right_motor.stop()

detected = color_sensor.color()
print(f"Color detected: {detected}")
if detected == Color.RED:
    print("🔴 STOP! Red detected.")
else:
    print("✅ Path clear.")

🔧 LED Blink — Your First Circuit

1

Install Arduino IDE and upload Blink example

Download Arduino IDE from arduino.cc/en/software (free). Connect the board with USB. Go to File → Examples → 01.Basics → Blink and click Upload ➜.

✅ The built-in LED on pin 13 will blink once a second. Congratulations — you just programmed hardware!
2

Wire an external LED on the breadboard

Follow this exact wiring. The 220Ω resistor protects the LED from burning out.

⚠️ Safety: NEVER connect an LED directly to 5V without a resistor — it will burn out instantly!
3

Upload the blink code for the external LED

Arduino C++ — LED Blink (Pin 13)
// Pin 13 has the built-in LED on most Arduino boards
const int LED_PIN = 13;

void setup() {
    // Tell Arduino: pin 13 is an OUTPUT
    pinMode(LED_PIN, OUTPUT);
    Serial.begin(9600);
    Serial.println("Arduino ready! LED will blink.");
}

void loop() {
    // Turn LED ON
    digitalWrite(LED_PIN, HIGH);
    Serial.println("LED: ON  ●");
    delay(500);  // wait 500 milliseconds

    // Turn LED OFF
    digitalWrite(LED_PIN, LOW);
    Serial.println("LED: OFF ○");
    delay(500);
}
4

Add a push button to control the LED

Button controls LED
const int LED_PIN    = 13;
const int BUTTON_PIN = 2;

void setup() {
    pinMode(LED_PIN,    OUTPUT);
    pinMode(BUTTON_PIN, INPUT);  // button on pin 2
    Serial.begin(9600);
}

void loop() {
    int btnState = digitalRead(BUTTON_PIN);
    if (btnState == HIGH) {
        digitalWrite(LED_PIN, HIGH);
        Serial.println("Button pressed → LED ON");
    } else {
        digitalWrite(LED_PIN, LOW);
    }
}

Write the Python blink program

Python — GPIO LED Blink (save as blink.py)
import RPi.GPIO as GPIO
import time

# Set BCM numbering (matches GPIO numbers on diagrams)
GPIO.setmode(GPIO.BCM)

LED_PIN = 17
GPIO.setup(LED_PIN, GPIO.OUT)

print("🔴 LED blink program started. Ctrl+C to stop.")

try:
    while True:
        GPIO.output(LED_PIN, GPIO.HIGH)   # LED ON
        print("● ON ")
        time.sleep(0.5)

        GPIO.output(LED_PIN, GPIO.LOW)    # LED OFF
        print("○ OFF")
        time.sleep(0.5)

except KeyboardInterrupt:
    print("\nStopped by user.")

finally:
    GPIO.cleanup()   # ALWAYS cleanup to reset pins
    print("GPIO cleaned up. Safe to exit.")
💻 Run with: python3 blink.py in the terminal. SSH into the Pi first!

🎉 Next: Camera + Face Detection

Python OpenCV — Detect faces with Pi Camera
import cv2

# Load pre-trained face detection model
face_cascade = cv2.CascadeClassifier(
    cv2.data.haarcascades + 'haarcascade_frontalface_default.xml'
)

# Open Pi Camera
cap = cv2.VideoCapture(0)

print("Starting face detection. Press 'q' to quit.")

while True:
    ret, frame = cap.read()
    gray  = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    faces = face_cascade.detectMultiScale(gray, 1.1, 5)

    for (x, y, w, h) in faces:
        cv2.rectangle(frame, (x,y), (x+w,y+h), (0,255,0), 2)
        print(f"Face detected at ({x},{y}) size {w}×{h}")

    cv2.imshow('Face Detection', frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

🔧 mBot Assembly Guide

1

Assemble the chassis frame

Lay the acrylic base plate flat. Attach the two motor brackets to the underside using M3 screws (4 per motor). The gear box faces outward. Don't overtighten — just snug.

2

Mount the mCore board and connect motors

Screw the mCore onto the top of the chassis (4 standoff pillars). Connect the left motor to M1 and the right motor to M2 using the RJ25 cables (they only fit one way).

🔌 RJ25 cables look like phone cables. They click into the ports and can only be inserted one way — don't force them.
3

Attach the Ultrasonic Sensor to the front

Screw the ultrasonic sensor bracket to the front face of the chassis. Plug the RJ25 cable into Port 3 on the mCore board. The two "eyes" (Trig/Echo) face forward.

4

Attach Line-Follow Sensors to the underside

Mount the line-follow sensor bracket on the underside front, about 3–5 mm above the ground. Connect to Port 2. The two IR eyes should point directly down at the floor.

📏 Height matters: Too high = misses the line. Too low = bumps the ground. Test with a piece of white paper and a black tape line.
5

Install 4 × AA batteries and power on

Slide the battery holder into the base plate. Switch the power toggle to ON. Both RGB LEDs should flash pink/purple for 2 seconds — that means the board is ready.

🔋 Use alkaline batteries (not rechargeable NiMH). The lower voltage of NiMH can cause motors to spin slowly or the board to reset mid-run.
6

Program with mBlock (Scratch-based IDE)

Download mBlock 5 (free). Connect via USB or Bluetooth. Drag the Move Forward block and click Run — your robot drives!

mBot Obstacle Avoider — Arduino C
#include <MeMCore.h>

MeDCMotor motorL(M1);
MeDCMotor motorR(M2);
MeUltrasonicSensor us(PORT_3);

void setup() {
    Serial.begin(9600);
}

void loop() {
    float dist = us.distanceCm();
    Serial.print("Distance: "); Serial.print(dist); Serial.println(" cm");

    if (dist > 20) {
        // Clear path — drive forward
        motorL.run(-200);
        motorR.run( 200);
    } else {
        // Obstacle! — stop and turn right
        motorL.stop();
        motorR.stop();
        delay(300);
        motorL.run(-200);   // spin right
        motorR.run(-200);
        delay(500);
    }
    delay(50);
}

🔧 VEX IQ Clawbot Assembly Guide

1

Understand the VEX IQ snap-fit system

VEX IQ uses injection-moulded ABS plastic beams, pins, and connectors. No tools needed — everything snaps together. Red pins are structural (permanent), black pins are removable.

2

Build the drivetrain (4-wheel base)

Attach 2 double-beam rails as the left/right side chassis rails. Snap in 4 axle brackets. Mount a Smart Motor behind each rear wheel. Press the omnidirectional wheels onto the front axles.

3

Mount the IQ Brain and connect Smart Motors

Snap the IQ Brain onto the top-centre of the chassis using the beam holes. Connect the two drive motors to Ports 1 and 6. The VEX Smart cables click in firmly — you'll hear a snap.

⚡ Smart Ports auto-detect what's connected. No need to configure motor types in software — the Brain reads it automatically.
4

Build and attach the Clawbot arm

Build the arm using 2× 10-hole beams as the lift arm, connected to a Smart Motor on Port 3 via a 60-tooth gear. Mount the claw assembly at the tip — it connects to a motor on Port 4.

5

Program with VEXcode IQ Python

VEXcode IQ Python — Driver Control (Competition Ready)
from vex import *

brain  = Brain()
left   = Motor(Ports.PORT1, GearSetting.RATIO_18_1, False)
right  = Motor(Ports.PORT6, GearSetting.RATIO_18_1, True)
arm    = Motor(Ports.PORT3, GearSetting.RATIO_18_1, False)
claw   = Motor(Ports.PORT4, GearSetting.RATIO_18_1, False)
ctrl   = Controller()

brain.screen.print("VEX Clawbot Ready!")

# Driver-control loop
while True:
    # Tank drive: left stick Y → left motor, right stick Y → right motor
    left.spin(FORWARD,  ctrl.axisA.value(), PERCENT)
    right.spin(FORWARD, ctrl.axisD.value(), PERCENT)

    # ButtonL2 / ButtonR2 → raise/lower arm
    if ctrl.buttonL2.pressing():
        arm.spin(FORWARD, 80, PERCENT)
    elif ctrl.buttonL1.pressing():
        arm.spin(REVERSE, 80, PERCENT)
    else:
        arm.stop(HOLD)

    # ButtonR1 / ButtonR2 → open/close claw
    if ctrl.buttonR1.pressing():
        claw.spin(FORWARD, 80, PERCENT)
    elif ctrl.buttonR2.pressing():
        claw.spin(REVERSE, 80, PERCENT)
    else:
        claw.stop(HOLD)

    wait(20, MSEC)
